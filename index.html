CronoQuiz is a YouTube channel that publishes video game trivia quizzes, both long-form videos and Shorts. CronoQuiz Studio is the software we use to create those videos.

This is not a public service. CronoQuiz Studio is a desktop application that runs only on the channel owner's computer. It has no public sign-up, no other users and no web interface. This page exists to describe the tool and to host its privacy policy.

What the tool does

  • Generates video game quiz questions and lets the channel owner review them.
  • Renders the final video (MP4) locally.
  • Uploads the finished video to our own YouTube channel, youtube.com/@CronoQu1z, as a private video with its title, description, tags and playlist, scheduled to become public at a chosen date.

How it uses YouTube API Services

CronoQuiz Studio uses the YouTube Data API only to upload and organize videos on the channel owner's own channel. It does not access, read or store data from any other user or channel. See the Privacy Policy for details.
